Projeto Arkanoid Lite;
Meu primeiro codigo funcional;
Programado em C++ pelo Code:Blocks;
Feito para o primeiro trabalho da disciplina de Algoritmos e Programação 2;
Os requisitos foram:

Funcionalidades 60% 0.4 cada:
• O Paddle se move para a direita e esquerda.
• A Bola não passa as paredes laterais.
• A Bola não passa o Paddle.
• A Bola começa no centro e se move em direção aleatória.
• O Jogador perde o jogo quando a bola não é rebatida pelo Paddle. 
• Os Blocos quebram ao serem atingidos pela bola.
• Os Blocos somam pontos ao serem quebrados. 
• O sistema de pontos incrementa corretamente ao quebrar os blocos. 
• Os pontos acumulados aparecem em tela durante o jogo.
• A Bola deve ricochetear nas paredes 
• A Bola deve ricochetear no Paddle.
• A condição de vitória é corretamente atingida quando todos os blocos são destruídos.
• O Jogo tem menu
• O Jogo tem instruções de Jogo
• O Jogo tem um sobre, com o que cada participante da equipe fez

• Subrotinas: Parâmetros e referencias corretos
